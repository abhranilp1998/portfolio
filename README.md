# Abhranil Paul — Portfolio

**Live:** https://abhranilp1998.github.io/portfolio/

A single-page personal portfolio site with my background, experience, featured projects and a way to get in touch. I'm a software developer working with T-SQL, ERP systems, .NET and Flutter.

## Stack

- Plain HTML, CSS and JavaScript (no framework, no build step)
- [Ionicons](https://ionic.io/ionicons) for icons, Google Fonts for type
- [FormSubmit](https://formsubmit.co) for the contact form
- Hosted on GitHub Pages

## Run locally

```bash
git clone https://github.com/abhranilp1998/portfolio.git
cd portfolio
python3 -m http.server 8000   # or: npx serve .
```

Then open http://localhost:8000.

## Structure

```
index.html            # all page content
assets/css/style.css  # styles
assets/js/script.js   # navigation, testimonials modal, contact form
assets/images/        # images (WebP)
```
